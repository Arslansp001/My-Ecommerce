# KitchenNest Ecommerce Website

A customer-focused ecommerce storefront for selling kitchen accessories.

## Highlights
- Conversion-oriented hero section with trust signals and urgency offer.
- Product discovery with search, category filtering, and sorting.
- Dynamic cart drawer with add/remove and live total updates.
- Social proof with customer testimonials.
- Newsletter lead capture with discount code flow.
- FAQ section to reduce purchase friction.

## Run locally
```bash
python3 -m http.server 4173
```
Then open `http://localhost:4173`.

Ticketing App Dependencies (Ubuntu VM)
======================================

1) System-level prerequisites
- Docker Engine (already installed)
- Docker CLI plugin / Docker Compose plugin (optional, only for reference)
- Node.js and npm (already installed)
- curl (for API testing)

2) Container images used
- postgres:16-alpine
- node:20-alpine (backend build/runtime base)
- nginx:1.27-alpine (frontend runtime)

3) Backend npm dependencies (backend/package.json)
- express ^4.19.2
- pg ^8.12.0
- dotenv ^16.4.5

4) Network and runtime resources
- Docker network: app-network
- Docker volume: ticketing-pgdata
- Containers:
  - frontend (Nginx, port mapping 8080:80)
  - backend (Express, port mapping 5000:5000)
  - backend_db (PostgreSQL, internal 5432)

5) Environment variables (backend)
- PORT=5000
- DB_HOST=backend_db
- DB_PORT=5432
- DB_USER=postgres
- DB_PASSWORD=postgres
- DB_NAME=ticketing
